# OZARIUM™ — Film Prop Mockups (FICTIONAL)

**These are production props for a movie.** Everything in this directory is
fictional and intended only as on-screen set dressing for a story element
depicting a "scammy supplement funnel."

- **OZARIUM™**, "Ozarium Wellness Labs," the "Ozonated Oil Elixir," and the
  "Ozonated Face Cream" are **invented brands/products**. Any resemblance to
  real companies or products is unintentional.
- All names, handles, avatars, testimonials, comments, review counts,
  "doctors," and health claims are **fabricated for narrative purposes** and
  are deliberately written as parody of deceptive marketing.
- Do **not** use these assets, or derivatives of them, to market any real
  product. They are not marketing material and contain intentionally false
  claims.

## Files

| File | What it is |
|---|---|
| `phone-social-feed.html` | Phone-framed social feed: 7 posts with threaded supporting comments |
| `desktop-social-feed.html` | Desktop browser version of the feed with sidebar |
| `funnel-landing-desktop.html` | ClickFunnels-style parody sales page, desktop |
| `funnel-landing-phone.html` | Same funnel page in a phone frame |

Open any file directly in a browser and screen-record/screenshot for the shot.
All files are fully self-contained (no network requests), so they render
identically on set with no internet.
