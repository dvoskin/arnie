## THE FOUR THINGS THAT WILL BITE YOU

1. **A function that is called is not a function whose result is used.** Three
   defects this session survived gates that only proved invocation. Assert on
   RETURNED values. A stub is a statement about the CONTRACT, never evidence the
   stubbed thing exists.
2. **An instrument that approximates its subject cannot discover that its
   subject is broken.** A coverage number said memory carried 44.6% while the
   rung returned 0% for all 836 rows.
3. **`| tail` returns tail's exit code.** A red run reported exit 0. Write suite
   output to a file, read the file, never pipe.
4. **A run that races an edit measures neither version.** Clear `__pycache__`
   and do not edit while a suite is running.
