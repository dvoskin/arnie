## ⛔⛔⛔ STANDING METHOD — the ordering, now the standard

```
pin environment  ->  prove the defect exists  ->  measure its base rate
                 ->  ONLY THEN investigate cause
```

Today violated this three times and paid for it each time:

- a **100-turn baseline frozen** under a shell where all 18 declared flags were
  unset — reversed two published conclusions;
- **three discrimination rounds (~60 turns)** run against a defect whose base
  rate had never been established;
- a **three-ask sample over-read** as refuting that defect, having earlier
  over-read three runs as establishing it. The true rate is ~60 %: below the
  first claim, far above the second.

**Every experiment that lacked a known-good control produced either a void arm
or a false conclusion.** A discrimination set without a control cannot
distinguish a finding from a broken harness — `KeyError: 201` presented as
"every case omits" until the controls contradicted it.

**Next round: ONE discriminating experiment at a time against the pinned
baseline.** Find what changes omission probability between a reproducing case
and a matched control. No policy, no DEFAULTABILITY changes, no prompt work
until the cause is isolated.

## ⛔⛔⛔ GUARD 5 — PROBE ELIGIBILITY (the last methodological hole)

> **A probe is eligible only if the EXACT utterance reached the behaviour under
> test, under the SAME pinned config and tree, BEFORE it enters the
> experiment.**

Stronger than *"we expect this to ask."* Two D1 rounds died here: round 1 had
two of six semantic probes never ask; round 2 had c301 ask 0/3. Both chose
utterances for the property being TESTED without verifying they exhibit the
behaviour the test REQUIRES. ~18 wasted turns — and worse, **an absent
behaviour read as evidence about its cause.**

**Failed eligibility is FATAL TO THE ARM, never "0 asks observed."** Recording
a miss as data is exactly how rounds 1 and 2 went wrong.

⭐ **Eligibility is NOT power.** A probe asking 5 of 8 is eligible; whether the
run yields enough asks to decide anything is the separate INSUFFICIENT rule.

Enforced: `scripts/probe_eligibility.py` + `data/probe_eligibility.json`, called
by the harness BEFORE the first turn (`PROBE_QUALIFY=1` for a qualification
pass, whose purpose is to run utterances that may not qualify). 6 tests,
mutation-verified **4 RED / 0 GREEN**. The three arm-killing utterances are
registered ineligible **so they cannot be reused** — the harness now refuses the
exact experiment that wasted the turns.

## THE CAUSAL-EXPERIMENT CONTRACT

```

```
